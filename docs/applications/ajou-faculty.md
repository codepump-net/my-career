# 아주대학교 디지털미디어학과 교수 지원 — 범용 기본 문서

기준일: 2026-09-19. 특정 채용 공고·직급·트랙을 전제로 하지 않는다.
사용자 요청에 따라 OVERDARE 지원을 종료하고 교수 지원 자료로 중심을 전환했다.

## 현재 문서

- [CV](../../cv/default/index.html): 기존 정본의 학력 → 논문 → 강의 → 산업·R&D → 수상.
- [커버레터](../../coverletter/default/index.html): 지원 동기, 교육 철학, 연구계획, 산학협력·학생 지도, 임용 후 기여의 작성 안내.
- [포트폴리오](../../portfolio/default/index.html): 표지, 개요, 연구, 교육, 산업, 향후 계획, 연락처, 증빙 부록의 8장.
- [OVERDARE 종료 기록](../archive/overdare/README.md).

## 근거와 작성 원칙

`cv/data.js`에 있는 기존 이력만 활용했다. 학력은 **박사 수료**로 유지한다.
현재 진행 중이라는 기존 이력 표현은 신규 확인한 사실이 아니므로 제출 전 갱신한다.
SCA 2006 논문을 임의로 추가 논문·연구비·지도 실적 등으로 확장하지 않는다.
산업 개발 성과와 학술 연구 성과, 과거 강의와 향후 제안 과목을 구분한다.
학교·학과의 현행 채용 기준이나 교과과정에 대한 적합성을 검증한 문서는 아니다.

저장소 작성 규칙에 따라 지원자의 동기·철학·향후 계획은 본인이 작성할 구체적 안내로 남겼다.
포트폴리오에는 기존 사실과 보완할 증빙을 구분했다. 아직 제출 완성본이 아니다.

- [ ] 학위 상태, 현재 소속 및 경력 기간, 연락처 갱신

- [ ] 대표 연구 그림·결과와 프로젝트 이미지·시연 자료 추가
- [ ] 강의계획 예시, 과제·평가 기준, 교육 철학 작성
