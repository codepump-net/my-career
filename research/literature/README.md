## 1. 세 연구 방향

사용자가 설정한 **Computer Graphics, AI 활용, MIS**를 각각 독립적인 문헌 조사 축으로 운영한다. 기존 계획서의 그래픽스 과제는 첫 번째 축의 후보로 유지하며, 박사학위의 최종 집중 주제는 세 분야의 신규성·데이터·실험 가능성을 비교한 뒤 정한다.

| 분야별 조사 문서 | 중심 질문 | 최고 수준 문헌의 우선 탐색 경로 | 초기 연구 후보 |
| --- | --- | --- | --- |
| [1. Computer Graphics](computer-graphics.md) | 3D 콘텐츠를 어떻게 표현·생성·제어·경량화할 것인가? | TOG·SIGGRAPH/SIGGRAPH Asia, CGF·Eurographics; 기하·애니메이션·성능별 전문 학회 | 기능 보존 메시 단순화, 생성 자산의 동작 검증 |
| [2. AI 활용](ai-applications.md) | AI가 제작·코딩·테스트를 얼마나 안정적으로 수행하는가? | JMLR·JAIR·TPAMI, NeurIPS·ICML·ICLR; 기여별 ACL·CVPR·CHI 등 | 실행 피드백 기반 개발 에이전트, 자동 플레이 테스트 |
| [3. MIS](mis.md) | 기술과 플랫폼 정책이 창작자·조직의 행동과 성과를 어떻게 바꾸는가? | AIS Premier Journals 11개, ICIS; ECIS·AMCIS·PACIS | 숙련도별 AI 효과, 창작자의 플랫폼 영향, 통제권과 기여 |

표의 탐색 경로는 분야별 공식 범위와 이번 과제의 적합성을 바탕으로 정한 읽기 우선순위다. 근거 링크와 학회·저널의 출판 구분은 각 문서에 정리했다. 서로 다른 분야를 하나의 숫자 순위로 환산하지 않는다.

## 2. 조사 방법과 해석 기준

- **학술지·학회 선정:** 학회·출판사의 공식 소개·CFP·프로시딩을 우선한다. MIS는 AIS의 공식 Premier Journals 목록을 기준으로 한다. 그래픽스·AI에는 이번 조사에서 적용할 공통 공식 순위가 없어 대표 출판 경로와 전문 주제 적합성을 구분했다.
- **최신성:** 2025~2026년 발표·게재·공개 자료를 우선했다. 현재 날짜 이후의 행사 결과는 추정하지 않는다. 사전공개 연도·온라인 게재일·학회 개최연도가 다르면 구분한다.
- **대표 문헌 선정:** Roblox 직접 연구 또는 Roblox의 제작·실행·창작자 생태계로 연결할 수 있는 방법·이론을 선택했다. 전수 조사나 체계적 문헌고찰의 완결본은 아니다.
- **근거의 종류:** 동료심사 논문, 학회 Short Paper/TREO, arXiv 연구 원고, 기업 기술·제품 발표를 따로 표시했다. 서지·초록·공개 설명을 확인한 1차 조사이며 모든 원문·부록의 정독과 재현을 완료한 것은 아니다.
- **관련성:** ‘직접’은 Roblox 연구·데이터·자료, ‘전이 후보’는 다른 환경에서의 결과를 Roblox에 적용할 가능성이다. 후속 질문과 투고처 적합성은 제안이며 검증된 신규성·채택 가능성이 아니다.
- **위상:** 영향력 지수·채택률·대학 인정 기준을 확인 없이 적지 않았다. ‘최고 수준’은 대표적 연구 출판 경로를 찾기 위한 기준으로 사용하며 모든 전문 학회·탐색 자료를 같은 등급으로 취급하지 않는다.

검색은 공식 웹페이지와 출판사·학회 검색 결과를 사용했다. 주요 검색식은 각 문서 마지막 절에 남겼다. 접근이 제한된 원문은 확인 범위를 명시하고, 상세 실험 결과를 추정하지 않았다.

## 3. 세 분야의 경계와 연결

예를 들어 ‘AI가 생성한 문이 제대로 열리지 않는다’는 같은 현상을 다음과 같이 연구할 수 있다.

| 분야 | 독립적인 연구 질문 | 주요 증거 |
| --- | --- | --- |
| Computer Graphics | 관절·접촉을 보존하는 기하 보정이 가능한가? | 형상·관통 오차, 동작 성공률, 계산 비용 |
| AI 활용 | 에이전트가 실패를 진단하고 수정할 수 있는가? | 작업 완수·회귀 오류·수정 횟수·모델 비용 |
| MIS | 이런 도구의 통제 방식이 숙련도별 생산성과 지속 참여를 바꾸는가? | 처치·비교 집단, 과정 로그, 행동·성과·이론적 메커니즘 |

세 축은 자산과 도구 일부를 공유할 수 있지만 하나의 실험 결과를 세 논문의 독립 기여로 반복 사용하지 않는다. 각 원고의 질문·기여·증거를 구분하고 관련 연구와 데이터 재사용을 밝힌다.
