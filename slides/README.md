# 슬라이드 덱 (16:9)

`slides/shared/` 는 16:9 발표용 덱의 런타임과 반응형 셸이다. 내비게이션, 딥링크, 언어 전환,
전체화면, 접근성 상태, 모바일 대응, **PDF 추출용 인쇄 레이아웃**을 이 폴더가 책임진다.

현재 이 체계를 쓰는 페이지는 `/portfolio` 하나다.
`/cv` 와 `/coverletter` 는 A4 세로 문서 체계를 쓴다 — [`paper/README.md`](../paper/README.md) 참고.

```text
portfolio/
  index.html       # 버전 목록 페이지 (링크만)
  data.js          # KO/EN 문구 정본
  default/         # 버전 하나 = 폴더 하나
    index.html     #   슬라이드 마크업
    version.js     #   슬라이드 순서·구성 (DECK_VERSION.slides)
slides/shared/
  deck.css         # 공용 셸 + 임시 슬라이드(temp-*) 레이아웃 + 인쇄 규칙
  deck.js          # 공용 컨트롤러 (버전 로드 + 셸 UI 문구)
```

## 버전

버전 하나가 폴더 하나다. `/portfolio/` 는 목록만 보여 주고 실제 덱은 `/portfolio/<이름>/`
에 있다. 문서(A4)와 달리 **덱은 마크업 자체가 내용**이라 버전마다 슬라이드 마크업을 갖는다.

`version.js` 의 `slides` 가 순서와 구성을 정한다. 마크업에 있어도 `slides` 에 없는 장은
DOM 에서 제거되어 화면에도 PDF 에도 나오지 않고, 순서도 `slides` 에 맞춰 DOM 을 재배치하므로
PDF 페이지 순서가 화면과 같다.

기본판이 아닌 버전은 열람 시 자동으로 `noindex` 가 붙는다.

새 버전은 `default/` 폴더를 복사해 만든다. 마크업이 복사되므로, 슬라이드 레이아웃을 고칠 때는
버전마다 손봐야 한다 — 문구는 `data.js` 하나만 고치면 된다.

## 새 슬라이드를 추가할 때

1. `index.html` 의 `#deckStage` 안에 `<section class="slide" data-slide="<id>">` 를 추가한다.
2. `versions/<이름>.js` 의 `slides` 에 같은 `id` 를 순서대로 넣는다.
   **배열 순서가 곧 슬라이드 순서**이며, 마크업 순서는 참고하지 않는다.
3. 번역이 필요한 문구는 마크업에 `data-deck-key="<키>"` 를 달고 `data.js` 의
   `ko`/`en` 양쪽에 같은 키를 추가한다. 한쪽이 비면 `ko` 값으로 대체된다.

`slides` 항목 옵션

| 키 | 뜻 |
| --- | --- |
| `id` | `data-slide` 값과 짝을 이루는 식별자 (필수) |
| `enabled: false` | 아직 공개하지 않을 장. DOM 에서 제거되어 PDF 에도 빠진다. `?preview=all` 로 확인할 수 있다 |
| `appendix: true` | 부록으로 표시. 본편과 번호를 따로 세고, 진행 바는 본편 기준으로 계산한다 |

## 조작

| 입력 | 동작 |
| --- | --- |
| `→` `PageDown` `Space` | 다음 슬라이드 |
| `←` `PageUp` | 이전 슬라이드 |
| `Home` / `End` | 처음 / 마지막 |
| `F` | 전체화면 토글 |
| 좌우 스와이프 | 슬라이드 넘김 (모바일) |
| `#/3` | 3번 슬라이드로 바로 진입 |
| `?lang=en` | 언어 지정 진입 (선택값은 `localStorage.language` 에 남는다) |

## PDF 추출

상단 바의 PDF 버튼(또는 `Ctrl`/`Cmd` + `P`)을 누르면 브라우저 인쇄 대화상자가 열린다.
버튼을 쓰면 화면에 보이지 않던 장의 이미지까지 강제로 내려받은 뒤 대화상자를 연다.

저장 설정

- 대상: **PDF로 저장**
- 용지: `deck.css` 의 `@page { size: 1280px 720px }` 가 지정하므로 기본값 그대로 둔다
- 여백: **없음**
- 배경 그래픽: **켜기** (끄면 슬라이드 배경색이 빠진다)

슬라이드 1장이 PDF 1페이지가 된다. 현재 선택된 언어로 출력되므로, KO/EN 두 벌이 필요하면
언어를 바꿔 두 번 저장한다.

## 주의

- 슬라이드 내부 배치는 `px` 가 아니라 `rem` 을 쓴다 (1rem = 캔버스 기준 20px).
  화면에서는 뷰포트에 맞춰 배율이 변하고 인쇄에서는 20px 로 고정되는데, `px` 를 쓰면
  두 경로의 비율이 어긋난다.
- 이미지는 `portfolio/assets/` 에 둔다.
- `slides/shared/` 를 고치면 이 체계를 쓰는 모든 페이지에 적용된다. 한 덱에만 필요한
  스타일은 그 덱 폴더에 별도 CSS 를 두고 `deck.css` 다음에 링크한다.
